138// NOTE: with a single event queue and kernel preemption enabled, hard IRQs
139// post events to edas while kernel code RMWs the shared eda state byte
140// (is_ready shares one byte with is_timed etc., see __vsf_eda_state_t).
141// A no-op sched lock loses concurrent flag updates: on YC1615 a USB hard
142// IRQ preempting the is_timed RMW in __vsf_kernel_evthandler wiped is_ready
143// of an eda still linked in rdy_list; the next post double-enqueued it and
144// vsf_evtq_poll spun forever on the resulting list cycle (full system
145// freeze, proven by ICE dump). So under VSF_KERNEL_CFG_ALLOW_KERNEL_BEING_
146// PREEMPTED the lock/unlock stubs below mask interrupts instead.
147
159# if VSF_KERNEL_CFG_ALLOW_KERNEL_BEING_PREEMPTED == ENABLED

161# else

163# endif

177# if VSF_KERNEL_CFG_ALLOW_KERNEL_BEING_PREEMPTED == ENABLED

181# endif
