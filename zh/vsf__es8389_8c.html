◆ __VSF_AUDIO_CLASS_INHERIT__

#define __VSF_AUDIO_CLASS_INHERIT__
注解
ES8389 stereo audio codec control plane(i2c slave 0x20 default). Register facts + sequences learned from esp_codec_dev v1.6.2 (Apache-2.0, device/es8389/es8389.c) and re-expressed in vsf terms - no SDK text copied. The codec runs as i2s SLAVE with its clock recovered from BCLK(no MCLK pad), which is how the vendor reference boards wire it. The device stacks on vk_audio_i2s_dev_t: the audio data plane is entirely the generic i2s adapter's, this file only adds the codec register plane.
